# 🐾 AnimalSeeker

Асинхронный Python-скрипт для сбора списка всех животных с русскоязычной Википедии из категории [«Животные по алфавиту»](https://ru.wikipedia.org/wiki/Категория:Животные_по_алфавиту) и подсчёта количества записей на каждую букву алфавита. Результат сохраняется в файл `beasts.csv`.

---

## 📌 Пример результата

```csv
А,642
Б,412
В,317
...
```

Каждая строка содержит букву алфавита и количество страниц, начинающихся с этой буквы. Подсчитываются **все записи** из категории — не только названия животных, но и роды, семейства и т.д. (анализ содержимого страниц не требуется).

---

## 🚀 Стек технологий

* Python 3.12
* aiohttp
* BeautifulSoup (через lxml)
* CSV

---

## 🛠 Установка и запуск

### 1. Клонируйте репозиторий и перейдите на нужную ветку

```bash
git clone https://github.com/Leifr22/tetrika_tasks.git
cd tetrika_tasks
git checkout second_task
```

### 2. Установите зависимости

```bash
pip install aiohttp beautifulsoup4 lxml
```

### 3. Запустите скрипт

```bash
python solution.py
```

После завершения работы скрипта в директории появится файл `beasts.csv` с результатами.

---

## 🧪 Тестирование

```bash
pip install pytest pytest-asyncio
pytest
```

Файл `solution.py` уже содержит юнит-тесты для парсера.
