## 🧠 Учет времени совместного присутствия на уроке

### 📋 Условие задачи

Когда пользователь заходит на страницу урока, мы сохраняем **время его входа**. Когда пользователь **покидает урок** (закрывает вкладку или браузер), фиксируется **время выхода**.
Время присутствия каждого пользователя на уроке хранится в виде интервалов.

В функцию передаётся словарь с тремя ключами:

* `lesson` — список из двух таймстемпов: начало и конец урока.
* `pupil` — список таймстемпов с чередующимися входами/выходами ученика.
* `tutor` — список таймстемпов с чередующимися входами/выходами учителя.

Каждый интервал — пара значений: `[вход, выход, вход, выход, ...]`.

**Нужно реализовать функцию:**

```python
def appearance(intervals: dict[str, list[int]]) -> int:
    ...
```

Функция должна возвращать **время в секундах**, в течение которого **и ученик, и учитель одновременно присутствовали на уроке** (в пределах времени `lesson`).

---

### 🧪 Пример

```python
appearance({
    'lesson': [1594663200, 1594666800],
    'pupil': [1594663340, 1594663389, 1594663390, 1594663395, 1594663396, 1594666472],
    'tutor': [1594663290, 1594663430, 1594663443, 1594666473],
})
# Возвращает: 3117
```
