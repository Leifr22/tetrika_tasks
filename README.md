# 🧩 Задача: Декоратор `@strict`

## 📌 Условие

Реализовать декоратор `@strict`, который проверяет **строгое соответствие** типов переданных аргументов типам, указанным в аннотациях функции.

- При несоответствии типов выбрасывается исключение `TypeError`.
- Гарантируется:
  - Типы параметров — только `bool`, `int`, `float`, `str`;
  - У функций **нет значений по умолчанию**.

### ✅ Пример использования

```python
@strict
def sum_two(a: int, b: int) -> int:
    return a + b

sum_two(1, 2)      # ✅ 3
sum_two(1, 2.4)    # ❌ TypeError
````
